KRISHI SAKHI - HOW TO RUN
=========================

Full instructions: README.md

1. Backend (PowerShell window 1)
   cd krishi-sakhi-backend
   npm install
   copy .env.example .env      (then set GEMINI_API_KEY and JWT_SECRET)
   npm start                   -> http://localhost:3001  (check /api/health)

2. Frontend (PowerShell window 2)
   cd krishi-sakhi-frontend
   npm install
   npm run dev                 -> http://localhost:3000

Or run .\start.ps1 from this folder to open both.

Tests: cd krishi-sakhi-backend && npm test
